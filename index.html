Page 1Photosynthesis turns light energy into chemical energy. 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂.
Page 2Chloroplasts hold chlorophyll a and b, which absorb red and blue light and reflect green.

How the real app works
1. Ingest
PyPDF2 reads PDFs and docs. LangChain splits them into chunks and stores embeddings.
2. Retrieve
Each question pulls the most relevant chunks, so answers cite real pages.
3. Answer
Gemini writes the answer from those chunks only, which keeps it grounded.
4. Practise
Gemini also writes multiple-choice tests with explanations. The UI is built in Streamlit.
